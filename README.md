A faster drop-in for csv-reader 1.0.0: `solve.js` answers every case exactly as csv-reader does — same columns, rows and errors on broken CSVs — with a single left-to-right pass driven by `indexOf`, no dependencies and no regex in the hot path.

## Run it

```sh
node main.ts
```

The harness runs `node /bot/main.ts`; it reads cases from `/input/cases.json` and writes answers to `/output/answers.json`. Outside a container, `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` stand in for `/input` and `/output`.
